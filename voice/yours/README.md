# Your voice rules

Put your own rules here, one Markdown file per rule. `shortlist voice pack`
prints every `.md` file in this folder (this README excepted) after the default
pack, in filename order.

Good candidates: how you open and sign off, the headline you lead with, how you
describe an employer or a gap in your history, words you never use. Write each
rule as an instruction to the drafter, with an example if it is easy to misread.

The CLI never sends these files anywhere. Your agent reads them when it drafts,
so they reach whichever model your agent uses.
