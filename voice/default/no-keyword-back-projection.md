# No keyword back-projection

The drafter has read the job posting, and the posting is full of keywords: its
stack, its methods, its buzzwords. The pull is to reach for those words and
attach them to work that is adjacent but different. It sounds tailored. Under
one interview question it reads as deception.

A keyword from the posting goes into the CV or the letter only if the
candidate's work has that exact thing. If you would need to check a repository
to know whether the word applies, check it or leave the word out.

Understating is a mismatch too. Calling a system "read-only" when it also
writes fails the same check.

Name the limit inside the claim instead of rounding up: "built the first
version of the billing service", not "built the billing service", when only the
first version shipped. No invented durations ("for two years") and no rounder
numbers than the evidence gives.

Gaps are fine. A gap goes in the cover letter, stated once, plainly.
