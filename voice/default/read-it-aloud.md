# Read compressed clauses aloud

Read each sentence aloud before keeping it. If a trailing clause only parses
because you already know what it means, write the cause and effect out with
"so" or "because".

Before: "led the database migration, where downtime stayed at zero whatever the
traffic did"

After: "I ran the database migration behind a feature flag, so we could switch
back without downtime when traffic spiked."

Then check that the mechanism you name is the one that did the work.
Compressed sentences are where a small overclaim hides.
